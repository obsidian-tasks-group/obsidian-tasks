# How to read the user guide off-line

The Tasks user guide is an **Obsidian vault**. The online documentation is a published version of that vault, and you can also open a released copy locally in Obsidian.

## Open a released copy of the user guide in Obsidian

If you want an off-line copy of the Tasks user guide, the safest (and easiest) approach is to use a **released snapshot**.

1. Open the [Tasks releases page](https://github.com/obsidian-tasks-group/obsidian-tasks/releases).
2. Open the most recent release.
3. In the **Assets** section, download either:
    - **Source code (zip)**, or
    - **Source code (tar.gz)**
4. Expand the downloaded file.
5. In Obsidian, open the extracted `docs` folder as a vault.
6. Start reading from **Introduction**.

You can then read the user guide locally in Obsidian.

> [!note]
> You do **not** need to enable any plugins in that vault in order to read the documentation.
>
> For the best reading experience, keep the included CSS snippet enabled, so that the local vault looks closer to the published documentation.
