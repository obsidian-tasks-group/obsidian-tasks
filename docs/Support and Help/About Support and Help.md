## How to support an existing request

It is helpful to know which bug reports and feature requests would benefit the most users, so please show your support for existing requests that you would be likely to use or benefit from.

GitHub provides different ways to do this in Issues and Discussions, and this project has used both over time.

> [!warning]
> Please do not add `+1` comments. They add no actionable information, but they do create extra notifications and interruptions. Requests that receive them are generally de-prioritised on this project. To support an existing request, see below.

### Supporting Issues

To support an existing Issue:

1. Open the Issue.
2. In the first message, click **React**.
3. Select **Thumbs up (👍)**.

If someone has already added a 👍 reaction, you can click that existing reaction instead.

### Supporting Discussions

To support an existing Discussion:

1. Open the Discussion.
2. In the first message, click the **Upvote (↑)** icon.

If you do not find an existing item, see [[Report a Bug]] or [[Request a Feature]].
