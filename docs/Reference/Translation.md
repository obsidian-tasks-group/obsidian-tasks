# Translation

## Overview

Some parts of the Tasks plugin's user interface have been translated into languages other than English.

So far, these parts of Tasks are translated:

- the [[Settings]] pane
- the [[Editing a Status|status editing]] modal
- the [[Check your Statuses]] report

We will gradually translate more parts of Tasks in future releases.

## Choosing the language

Tasks does not have its own language setting. It uses the language that you have selected in Obsidian's own settings, under **Settings** → **General** → **Language**.

If Obsidian's language is not one of those listed below, or if a particular piece of text has not yet been translated into your language, Tasks shows the English text.

## Contributing translations

Translations are contributed by Tasks users. If you would like to improve an existing translation, or add a new language, see [Contribute translations](https://publish.obsidian.md/tasks-contributing/Translation/Contribute+translations) in the Contributing guide.
